# 团队工作台体验改进（测试版）

本记录保存 2026-11-24 的测试验收范围。2026-11-25 已按用户授权同步正式版，未迁移测试数据；当前部署结果见 [正式部署记录](release-20261125.md)。以下“测试版”描述为最初验收时的状态。

## 已实现范围

| 功能 | 行为与边界 |
| --- | --- |
| 统一内容编辑 | Codex 使用提示、网站公告、财务公告共用图文编辑、阅读预览、图片插入与未保存关闭提醒。正文最多 8000 字；旧公告不批量改写，公告没有自动草稿。 |
| 资源筛选 | GPT 按可用、到期、额度、重新授权筛选，支持到期和额度排序；Coding Plan 支持额度筛选排序，中转站支持关键词搜索。多工作区按已确认规则汇总，未知额度不算零。 |
| 财务审核详情 | 宽屏左右显示申请历史与附件，窄屏上下排列，底部保留审核操作；沿用原审批权限、历史保护与大图预览。 |
| 组别总览 | 默认显示前三位成员，其余通过 `+N` 查看；固定表头和类别列，长文字省略，滚动限定在表格区域。 |
| 页面偏好 | 筛选、API 日志显示列与分页数量按账户保存至服务器；不保存关键词。当前会话内按功能恢复滚动位置，关闭详情不跳回顶部。 |
| 异常提醒 | 顶部铃铛新增资源/API 提醒，仅已到期、额度耗尽、授权失效；恢复后再次失效重新提醒。权限撤销后不再显示，API 仅本人及管理员可见。 |
| 加密备份演练 | 独立样例运行每日北京时间 03:00 备份、保留 30 天、每周恢复校验。管理员可见备份状态及失败通知。正式数据尚未启用此计划。 |

## 数据与访问

- 网站和财务公告在原表追加可空结构化正文；原正文继续用于搜索与兼容读取。发布、编辑、置顶仍各自授权。
- `view_preferences` 保存账户与页面范围的白名单设置。服务端拒绝额外字段，客户端按顺序保存，迟到响应不会覆盖用户刚修改的筛选。
- 资源提醒基于已有资源状态；API 额度后台读取已初始化的用户映射，不新建网关账户、不调用模型。上游暂时不可用时保留原已知状态，不宣告恢复；通知列表不等待外部轮询。
- 备份将 SQLite 一致性副本、附件和指定的应用恢复密钥共同加密；解密密钥独立保存。当前运行的是隔离样例，不代表现有测试或正式业务数据已经获得定期备份保护。

## 验证与后续同步

- 自动验证覆盖公告正文校验、图片权限与范围、编辑冲突及未保存保护；偏好账户隔离、请求顺序和迟到恢复；通知权限、恢复去重、分页和慢上游；财务详情、导航和组别布局回归。
- 备份验证覆盖活动 WAL、密钥和路径边界、加密认证、文件哈希、数据库完整性、隔离恢复、保留期、计划幂等及失败通知。恢复校验不等于完整应用登录/解密演练，正式启用前仍需使用真实部署副本完成演练。
- 浏览器验收使用测试预览，保留原业务记录、附件和用户打开的草稿，不提交真实审批或公告。
- 本地 uv 后端回归 155 项、前端回归 181 项通过；账户/组别/提示的补充检查 52 项通过、1 项跳过。浏览器确认了桌面/窄屏编辑与预览、未保存提醒、资源筛选刷新恢复、API 日志列与分页恢复、现有图文提示读取、并排财务详情和提醒显示，未发现控制台错误。
- 测试服务重启前后，原业务表记录数及财务附件 SHA-256 一致，原草稿保留。通知停止时等待正在进行的写入，并停止启动排队的上游查询，避免服务关闭后残留后台写入。
- 正式同步前需要另行确认；不能将隔离样例的备份配置直接用于正式环境。配置说明见 [备份演练](../deploy/backup-test.md)。
